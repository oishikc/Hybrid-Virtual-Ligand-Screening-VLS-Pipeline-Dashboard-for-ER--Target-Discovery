# Hybrid-Virtual-Ligand-Screening-VLS-Pipeline-Dashboard-for-ER--Target-Discovery
Hybrid-VLS is an automated Python pipeline that integrates deep learning (DeepPurpose) and 3D biophysical docking (AutoDock Vina) to screen FDA-approved drug libraries for ER-alpha molecular docking, serving complete candidate data and toxicological profiles via an interactive Streamlit dashboard.
